PUZZLE #176: THE START

The Start

Puzzle #176 from page 97 of The Classic Train Track Logic Puzzle Book by Peter Kelby.

Start by scanning columns A to H, then rows 1 to 8. Continue to repeat those scans as the clues start to emerge.

Remember

  • A dot means the square must have track.
  • X means the square is empty.
  • Draw a simple line to mark the track once you figure out the direction.

The small letters and row numbers in the diagrams identify squares. B2 means column B, row 2.

Each diagram shows the position after the instructions beside it.

Step 1

Column A

  • The arrow at A5 means this square must contain track, so mark it with a dot.

Columns B to D

  • No new clues yet.

Column E

  • F7 connects with E7, so mark E7 with a dot.

Column F

  • F4 connects with F5, so mark F5 with a dot.
  • F7 connects with F8, so mark F8 with a dot.

Step 2

Column G

  • F4 connects with G4, so mark G4 with a dot.

Column H

  • The arrow at H3 means this square must contain track, so mark it with a dot.

Rows 1 to 7

  • No new clues yet.

Row 8

  • F8 cannot leave the grid, so it must have a connection to either E8 or G8.
  • For there to be only 3 track squares in this row, the remaining track square must also have an adjacent connection to E8 or G8. A8, B8 and C8 must be empty, so mark them with an X.

Step 3

Columns A to C

  • No new clues yet.

Column D

  • If D7 were empty, D8 would only have one possible connection, as C8 is empty and it cannot leave the grid.
  • That would leave only 6 available squares in Column D, but we need 7. So mark D7 with a dot – it has to be track.

Columns E to H and Rows 1 to 6

  • No new clues yet.

Row 7

  • We have our 3 track squares allocated, so mark the remaining squares with an X.

Step 4

Row 8

  • If G8 or H8 had track in them, they would lead to a dead end, so they must be empty – mark G8 and H8 with an X.
  • We need 3 track squares, so D8 and E8 must be track – mark them with a dot.
  • F8 can only connect F7 and E8 – draw in the connecting track.
  • D8 cannot go left or down, so it must join D7 with E8 – draw in the track.
  • E8 now has 2 connections – draw in the horizontal track.

Step 5

Columns A to F

  • No new clues yet.

Column G

  • We need 6 track squares. Two are marked as empty, so the remaining squares must all be track – mark them with a dot.

Column H

  • No new clues yet.

Row 1

  • G1 cannot connect upwards, so it must connect to F1 or H1. Since there are 3 track squares in Row 1, the remaining track square must be adjacent to this. This means A1, B1, C1 and D1 must be empty – mark them with an X.
  • This also means F1 must be track – mark it with a dot.

Step 6

Rows 2 to 6

  • No new clues yet.

Row 7

  • E7 has a connection to F7. This means D7 cannot connect to E7, so it must connect D6 and D8 – draw in the vertical track.
  • E7 now has only 1 possible orientation and must connect F7 with E6 – draw in the track.

Row 8

  • Completed.

Step 7

Columns A to B

  • No new clues yet.

Column C

  • We need 5 track squares, so mark the remaining squares with a dot.

Column D

  • We need 7 track squares, so mark the remaining squares with a dot.

Column E

  • E7 connects to E6, so mark E6 with a dot.

Columns F to H

  • No new clues yet.

Step 8

Rows 1 to 5

  • No new clues yet.

Row 6

  • We already have 4 track squares allocated and need 5. G6 cannot connect down, so it needs a connection to F6 or H6. This accounts for our remaining track square, so mark A6 and B6 with an X.
  • C6 cannot connect left or down, so it must connect C5 and D6 – draw in the track.
  • D6 now has 2 connections – draw in the track from C6 to D7.

Step 9

Row 6

  • If H6 were track, F6 would be empty. This would force both H5 and E5 to be track, giving Row 5 too many track squares, so H6 has to be empty – mark H6 with an X and F6 with a dot.
  • G6 cannot connect right or down, so it must connect G5 and F6 – draw in the track.

Row 7

  • Completed.

Step 10

Column A

  • If A3 were empty, A2 would have only one possible connection and would also be empty. That would leave only 2 available squares, but we need 3. So A3 must be track – mark it with a dot.

Column B

  • If B3 were empty, A3 would have to connect A2 and A4, giving Column A too many track squares. So B3 must be track – mark it with a dot.

Step 11

Columns C to H and Rows 1 to 2

  • No new clues yet.

Row 3

  • We already have our 6 track squares allocated, so mark E3 and F3 with an X.

Rows 4 to 6 and Columns A to E

  • No new clues yet.

Column F

  • We need 7 track squares and only 7 are available, so mark F2 with a dot.

Column G

  • No new clues yet.

Step 12

Column H

  • If H5 were track, it would connect H4 and G5. We would then have all 6 track squares allocated in Row 5, so E5 would have to be empty. If E5 is empty, F5 and E6 would then both have to connect to F6, which already connects to G6. That would give F6 three connections, so H5 must be empty – mark it with an X.
  • If H2 were empty, H1 would also have to be empty. That would leave only 2 available squares, but we need 3. So H2 must be track – mark it with a dot.

Step 13

Row 1

Row 2

  • C2 cannot connect up or left, so it must connect C3 and D2 – draw in the track.

Step 14

Row 2

  • F2 cannot connect left or down, so it must connect F1 and G2 – draw in the track.

Row 3

  • A3 cannot connect up or left, so it must connect A4 and B3 – draw in the track.

Step 15

Row 3

Row 4

Rows 5 to 6 and Columns A to D

Step 16

Column E

  • E4 cannot connect up or right, so it must connect D4 and E5 – draw in the track.

Column F

Step 17

Column G

Column H

  • We now have our 3 track squares allocated, so mark H4 with an X.

Step 18

Column H

  • H3 now has 2 connections – draw in the track from H2 to the exit arrow.

Step 19

Step 21

The Completed Route
