STEP-BY-STEP GUIDE

PUZZLE 051: THE START

The Start

Puzzle 051 from page 35 of The Classic Train Track Logic Puzzle Book by Peter Kelby.

Start by scanning columns A to H, then rows 1 to 8. Continue to repeat those scans as the clues start to emerge.

Remember

  • A dot means the square must have track.
  • X means the square is empty.
  • Draw a simple line to mark the track once you figure out the direction.

The small letters and row numbers in the diagrams identify squares. B2 means column B, row 2.

Each diagram shows the position after the instructions beside it.

Step 1

Column A

  • The arrow at A2 means this square must contain track, so mark A2 with a dot.
  • For Column A to have 2 track squares, the other must connect to A2 – so A1 or A3. Mark the other squares with an X.

Columns B to E

  • There are no new clues yet.

Column F

  • We need 8 track squares, so mark all the remaining squares with a dot.

Column G

  • We also need 8 track squares here, so mark all the squares with a dot.

Step 2

Column H

  • H1 can only connect on 1 side, so it cannot be track – mark it with an X.
  • We need 7 track squares, so mark the remaining squares with a dot.
  • H8 can only connect H7 and G8 (because of the grid edges) – draw in the track.

Step 3

Row 1

  • G1 cannot connect up or right, so it must connect F1 and G2 – draw in the track.

Row 2

  • We need 8 track squares, so mark the remaining squares with a dot.

Row 3

  • We already have 3 track squares allocated so mark the remaining with an X.

Step 4

  • We already have 3 track squares allocated so mark the remaining with an X.

Row 5

  • We already have 3 track squares allocated so mark the remaining with an X.

Row 6

  • We already have 3 track squares allocated so mark the remaining with an X.

Step 5

Row 7

  • We already have 3 track squares allocated so mark the remaining with an X.
  • F7 cannot connect up because the printed track in F6 turns right. It cannot connect left either, so it must connect G7 and F8 – draw in the track.

Row 8

  • We already have 3 track squares allocated so mark the remaining with an X.
  • F8 can only connect F7 and G8 (because of the grid edge and the X in E8) – draw in the track.
  • G8 now has 2 connections, so draw in the horizontal track between F8 and H8.

Step 6

Column A

  • We need 2 track squares and only 2 are available, so mark A1 with a dot.
  • A1 can only connect A2 and B1 (because of the grid edges) – draw in the track.
  • A2 now has 2 connections – draw in the track joining A1 and the arrow.

Column B

  • We also need 2 track squares here, so mark B1 with a dot.
  • B2 cannot connect left or down, so it must connect B1 and C2 – draw in the track.
  • B1 now has 2 connections – draw in the track between A1 and B2.

Step 7

Column C

  • We need 2 track squares, so mark C1 with a dot.

Column D

  • We also need 2 track squares here, so mark D1 with a dot.

Column E

  • We already have our 1 track square allocated, so mark E1 with an X.
  • E2 cannot connect up or down, so draw in the horizontal track between D2 and F2.

Step 8

Column F

  • F1 cannot connect up or left, so it must connect G1 and F2 – draw in the track.
  • F2 now has 2 connections – draw in the track joining F1 and E2.
  • F3 cannot connect up or left, so it must connect G3 and F4 – draw in the track.

Column G

  • G2 cannot connect left or right because those track pieces already have their two connections. Draw in the vertical track between G1 and G3.
  • G3 now has 2 connections – draw in the track joining G2 and F3.

Step 9

Column H

  • H3 cannot connect left or right, so draw in the vertical track between H2 and H4.
  • H4 now has 2 connections, so draw in the vertical track between H3 and H5.

Row 1

  • D1 can only connect C1 and D2 – draw in the track.

Step 10

Row 2

Step 11

Row 5

Step 12

Column G

  • G7 cannot connect down because G8 already has its two connections. It cannot connect to H7 either, as this would create a circular track through F7, F8, G8 & H8.
  • This means G7 must connect F7 and G6 – draw in the track.
  • G6 now has 2 connections – draw in the track joining F6 and G7.

Step 13

Column H

  • H6 cannot connect left or right, so draw in the vertical track between H5 and H7.
  • H7 now has 2 connections, so draw in the vertical track between H6 and H8.

The Completed Route

Congratulations!

You’ve traced the track from one arrow to the other. Every printed piece is used in one continuous route, with no branches, crossings or separate loops.
