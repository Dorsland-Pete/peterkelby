PUZZLE #052: THE START

The Start

Puzzle #052 from page 35 of The Classic Train Track Logic Puzzle Book by Peter Kelby.

Start by scanning columns A to H, then rows 1 to 8. Continue to repeat those scans as the clues start to emerge.

Remember

  • A dot means the square must have track.
  • X means the square is empty.
  • Draw a simple line to mark the track once you figure out the direction.

The small letters and row numbers in the diagrams identify squares. B2 means column B, row 2.

Each diagram shows the position after the instructions beside it.

Step 1

Column A

  • A3 connects to A4, so mark A4 with a dot.
  • We now have our 2 track squares allocated, so mark the remaining squares with an X.
  • A4 can't go left or down, so it must join A3 with B4 – draw in the track.

Step 2

Column B

  • B1 can only connect on 1 side, so it cannot be track – mark it with an X.
  • The track at A3 is connected to B3, so mark B3 with a dot.
  • A4 connects with B4, so it must be track – mark it with a dot.
  • We now have our 2 track squares – mark the rest with an X.

Step 3

Column C

  • B3 must connect with C3 (otherwise it'd create a loop) – mark it with a dot.
  • B4 must connect with C4 (otherwise it would make a loop) – mark it with a dot.

Column D

  • The track at C1 connects to D1, so mark D1 with a dot.
  • The track at D4 connects to D3, so mark D3 with a dot.

Step 4

Column E

Column F

  • The track at G4 connects to F4, so mark F4 with a dot.

Column G

  • The track at G4 connects to G3, so mark G3 with a dot.
  • The arrow at G8 means this square must contain track, so mark G8 with a dot.

Column H

  • There are no new clues yet.

Step 5

Row 1

  • We already have 2 track squares allocated, so mark the remaining squares with an X.
  • D1 can only connect C1 and D2 – draw in the track.

Row 2

  • The track at D1 connects to D2, so mark D2 with a dot.

Row 3

  • B3 must connect A3 with C3 to avoid making a loop through A3 and A4 – draw in the track.

Step 6

Row 4

  • We already have 7 track squares allocated, so mark H4 with an X.
  • B4 must connect A4 with C4 to avoid making a loop through A3 and A4 – draw in the track.
  • Joining C3 and C4 would make a loop through Columns A and B, so they cannot connect.
  • C4 can't go up or right, so it must join B4 with C5 – draw in the track.

Row 5

  • C4 connects with C5, so it must be track – mark it with a dot.

Step 7

Step 8

  • C5 can only connect C4 and D5 – draw in the track.

  • We now have our 5 track squares allocated, so mark the remaining squares with an X.

The Completed Route
