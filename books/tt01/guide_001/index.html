STEP-BY-STEP GUIDE

PUZZLE 001: THE START

The Start

Puzzle 001 from page 10 of The Classic Train Track Logic Puzzle Book by Peter Kelby.

Start by scanning columns A to F, then rows 1 to 6. Continue to repeat those scans as the clues start to emerge.

Remember

  • A dot means the square must have track.
  • X means the square is empty.
  • Draw a simple line to mark the track once you figure out the direction.

The small letters and row numbers in the diagrams identify squares. B2 means column B, row 2.

Each diagram shows the position after the instructions beside it.

Step 1

Column A

  • A4 is provided and connects to A3, so mark A3 with a dot.
  • We only need 2 track squares for Column A, so mark the other squares with an X.
  • We can see now that A3 must connect A4 and B3 – draw in the track.

Step 2

Column B

  • We can see that A3 is connected to B3 so mark B3 with a dot.
  • The only way to have two track squares in Column B is if another one connects to B3 (any other solution must be 1 or 3+ track squares) – so mark B1, B5 & B6 with an X as it cannot be them.

Column C

  • There are no clues yet.

Column D

  • There are no clues yet.

Column E

  • It needs 6 track squares so mark all the remaining squares with a dot.

Step 3

Column F

  • E3 connects to F3, so mark F3 with a dot.
  • F5 connects to F6, so mark it with a dot.
  • Since F3 must connect to E3, and E3 must connect to E4, F4 must be empty (otherwise it’d create a circular track between them) – mark F4 with an X.
  • Since we need 5 track squares, F1 & F2 must be track – mark them with a dot.

Step 4

Column F

  • F6 can only connect F5 to E6 (because of the grid edge) – draw in the track.
  • Also, F1 can only connect E1 to F2 – draw in the track.
  • F3 can only connect E3 with F2, which gives F2 two connections (F1+F3) – draw in the two track pieces.

Step 5

Row 1

  • We already have 2 track squares allocated so mark C1 & D1 with an X.
  • This means E1 must connect F1 and E2 – draw in the track.

Row 2

  • E2 can only connect D2 and E1 – draw in the track.
  • D2 now has a connection – mark it with a dot.
  • We need 1 more track square. If B2 connected to B3, it would also have to connect to C2 – this would give us too many track squares, so it must be empty – mark B2 with an X.
  • This leaves C2 which must be our 4th track square – mark it with a dot.
  • Now we can see that C2 can only connect D2 and C3, so draw in the track.
  • D2 now has 2 connections, so draw in the horizontal track.

Step 6

Row 3

  • All 6 squares contain track so mark C3 + D3 with a dot.
  • D3 cannot connect up or right, so it must connect D4 and C3 - draw in the track.
  • C3 now has 2 connections – draw in the track joining C2 with D3.

Row 4

  • We need 5 track squares, so mark the remaining squares with a dot.
  • Since B4 has only two possible connections, it must join B3 and C4 – draw in the track.
  • B3 now has two connections – draw in the track connecting B4 and A3.

Step 7

Row 5

  • We have 2 track squares allocated, so mark any others with an X.
  • Since E5 has only 2 possible connections, draw in the vertical track from E4 to E6.
  • This means E4 & E6 both now have two connections each – draw in the track pieces.

Row 6

  • We already have the 2 required track pieces, so mark C6 and D6 with an X.

Step 8

Column A

  • Completed

Column B

  • Completed

Column C

  • C4 only has 2 possible connections, so draw the track in horizontally between B4 and D4.
  • This establishes two connections for D4, so draw in the track connecting C4 and D3.

The Completed Route

Congratulations! You’ve traced the track from one arrow to the other. Every printed piece is used in one continuous route, with no branches, crossings or separate loops.

Column totals: 2, 2, 3, 3, 6, 5.

Row totals: 2, 4, 6, 5, 2, 2.
